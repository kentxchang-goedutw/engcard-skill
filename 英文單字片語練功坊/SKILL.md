# 英文單字片語練功坊

把一堆單字片語變成可反覆練習的單檔網頁：貼單字 → 按主題分組確認 → 生成四種模式練習頁。

## 交付成果

**一個 HTML 檔案**（單檔、雙擊即開，題庫內嵌免後端）：

| 畫面 | 內容 |
|------|------|
| 主畫面（開啟預設） | 標題、副標、搜尋列、各題庫卡片（組名、學習目標、字數、完成次數） |
| 模式選擇 | 📇單字卡、⌨️拼字練習、🧩字母重組、🎧聽音選單字，四宮格漸層按鈕 |
| 單字卡 | 看中文猜英文，點擊翻卡，背面顯示英文＋詞性＋例句，🔊朗讀 |
| 拼字練習 | 看中文用虛擬鍵盤拼英文，Aa大小寫切換＋退格，答對顯示例句 |
| 字母重組 | 點字母池排回正確順序，Aa切換，答對顯示例句 |
| 聽音選單字 | 自動播3次發音，三選一，答對顯示英文＋中文＋例句 |
| 頁尾 | `Made by 阿剛老師`（連到 `https://kentxchang.blogspot.tw`，`target="_blank" rel="noopener"`）與 CC BY-NC-SA 4.0 繁體中文授權說明 |

固定規格：馬卡龍配色（沿用參考 HTML 的 indigo/emerald/amber/rose）、圓角卡片、漸層背景、RWD、Web Speech API 發音、答對/答錯音效、隨機洗牌、HUD 即時耗時＋答錯次數、進度 `WORD x OF y`、練習次數 localStorage 保存。

## 執行流程

### 階段 1｜取得單字來源

1. 判斷來源：
   - 使用者貼上的文字 → 直接解析。每行 `英文[,，TAB]中文`，片語含空白屬正常（如 `check in,報到`）。
   - 使用者上傳檔案 → 用 Read 讀取。PDF/圖片用 Read 即可取得文字。
   - 網頁連結 → 用 WebFetch 取回內容再抽單字。
2. 缺中文的由 AI 補齊，並在階段 2 標示「AI 補中文」請使用者確認。
3. 若 PDF 是掃描版讀不到字，先問使用者要文字版還是直接描述內容，不要硬猜。
4. 詞性＋例句一併補上：`pos` 限 `n./v./a./ad./prep./conj./phr./sent.`，每字一個 `example_en`（須含該字核心詞）＋`example_zh`。

### 階段 2｜按主題分組並請使用者確認

1. 按語意主題/情境切組（例：機場報到、外食點餐），**每組 15–25 字**，3–6 組為宜。量少可只切 1–2 組。
2. **先用表格提案，然後停下來等確認：**

   | # | 組名 | 字數 | 主題/涵蓋範圍 | 例字 |
   |---|------|------|---------------|------|
   | 1 | 機場報到 | 20 | check in、登機相關 | check in、boarding pass… |

3. 明說可調整：改名、合併/拆分、增刪組、調字。**組名、數量、每組字表在此階段定案**；網頁不提供改題庫功能，改都在對話完成後重建。
4. 使用者確認後，以最終版本為階段 3 基準。

### 階段 3｜產出題庫 JSON

1. 讀 `references/vocab-spec.md` 取得完整欄位規格。
2. 寫成 JSON 檔（先寫工作資料夾下 `.tmp-vocab.json`）。
3. **必跑驗證：**

   ```bash
   node <本 skill 目錄>/assets/validate-vocab.js <vocab.json>
   ```

   有 `ERROR` 修到歸零才能往下。`WARN`（例句未含核心詞、疑似重複）逐條人工確認。

### 階段 4｜組出 HTML

1. 以驗證通過的 JSON 為 canonical 題庫。
2. 用打包腳本產生（檔名取自 `meta.title`）：

   ```bash
   node <本 skill 目錄>/assets/build-pages.js <vocab.json> <輸出目錄>
   ```

   產出 `<標題>-英文練習.html`。不要手改模板其他行；介面、邏輯、配色、頁尾授權都在模板裡，腳本會檢查佔位標記與作者連結。

### 階段 5｜自我檢查與交付

1. Node 檢查 HTML 內 `<script>` 語法無錯。
2. 確認：馬卡龍 token、`Made by 阿剛老師` 連結含 `target="_blank"`、CC 授權文字、四種模式按鈕都在。
3. 交付訊息包含：
   - 產出 HTML 完整路徑。
   - 切出幾組、各幾字、共幾字。
   - 玩法：開啟即主畫面 → 點題庫 → 選模式 → 看 `WORD x OF y` 練習 → 答對看例句 → 上/下一個切換 → 練習次數會保存。
   - 提醒：發音需連網瀏覽器支援 SpeechSynthesis；列印可直接用瀏覽器列印。
4. 最後問是否要調整分組或增刪單字（要改就重跑階段 3–4）。

## 紅線

- **不要捏造單字沒有的語意。** 缺中文寧可標示待確認，不要硬編冷僻義。
- **不要自己決定分組。** 未經使用者確認就進階段 3 是錯的。
- **不要每組少於 10 字或多於 30 字。** 15–25 為原則，特殊情況先告知。
- **不要在模板自行加功能。** 使用者另有要求才改，且只改必要行。
- **不要跳過 `validate-vocab.js`。**
- **不要輸出 `VOCAB = null` 的空模板**，也不要把題庫放外部 JSON（同源政策會擋）。
